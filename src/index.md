### This Is **NOT** a One Click Procedure

Installing an alternate operating system on your Chromebook is a technical process. You should be ready to troubleshoot and tinker. Make sure to read the docs and try Googling before asking for support!

### Need Help with ChromeOS?

The Chrultrabook Project is solely about running other operating systems on Chromebooks, we cannot help you with ChromeOS. Contact Google or try [r/chromeos](https://reddit.com/r/chromeos).
